# Python: Healthcare Insurance Data Analysis Project

## 📊 Project Overview 
* **Goal:** To analyze how different lifestyle factors, body metrics (BMI), and environmental conditions impact healthcare premium costs for ABC Insurance.
* **Dataset:** This project heps to create a model that will help to predict the cost of medical insurance based on various input features across 1300+ rows of insurance data.

---

## 🛠️ Tech Stack
The following tools have been used to analyse the data
* **Data Manipulation:** Python (Pandas, NumPy)
* **Data Visualization:** Matplotlib, Seaborn
---

## ⚙️ Project Workflow (How it Was Made)
1. **Data Prep:** Cleaned 1,300+ rows of data, removed duplicates, and handled null values.
2. **Data Framing:** Converted 1,337 cleaned rows of data into a structured dataframe using Pandas.
3. **Exploratory Data Analysis (EDA):** Used Matplotlib and Seaborn bar charts, histograms, boxplots, and heatmaps to identify correlations between various factors such as age, bmi, children and premium charges.
4. **Documentation:** Added clear conclusions after each analysis step for easier explanation, along with a Final Observation section at the bottom for a detailed overview of the analysis.

---

## 💡 Key Insights (What I Found)
* **Insight 1:** Factors such as Age, BMI and Smoking status have a significant impact on the Insurance premium charges.
* **Insight 2:** Smoking status has the most impact on the Insurance premium charges due to higher medical risk and treatment cost.
* **Insight 3:** Smokers and non smokers have to pay increasing premium as their age increases but Smokers have a much higher steep as compared to non smokers.
* **Insight 4:** Analysis also indicates other factors such as region, children, sex do not have much impact on the Insurance premium charges.
